    Settings

    General
    Wi-Fi
    Leave empty to keep the stored password.
    MQTT
    BMS
    Address = BMS DIP switches (all OFF = 0). Parallel packs use consecutive addresses.
    Security
    Protects settings, firmware update, restart and shutdown.
    Danger zone
    Switches the BMS off, like holding its button. It has to be woken up locally afterwards.

    Firmware update

    Upload seplos_controller.bin built for this chip. The previous firmware is kept and restored automatically if the new one does not start.
